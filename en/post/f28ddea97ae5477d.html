Matrices: linear transformations

A foundational mathematics node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ A = [a, b; c, d], \quad \det A = ad - bc \]

Code

def det2(a, b, c, d):
    return a * d - b * c

def matmul2(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(2)) for j in range(2)] for i in range(2)]
