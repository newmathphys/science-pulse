§ 5.4 · Computer science

Dijkstra: shortest paths

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ d(v) = \min_{(u,v) \in E} \left( d(u) + w(u, v) \right) \]

Code

import heapq

def dijkstra(graph, start):
    # Кратчайшие пути от start (Дейкстра, 1959)
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    queue = [(0, start)]
    while queue:
        d, node = heapq.heappop(queue)
        if d > dist[node]:
            continue
        for neighbor, weight in graph[node]:
            if d + weight < dist[neighbor]:
                dist[neighbor] = d + weight
                heapq.heappush(queue, (dist[neighbor], neighbor))
    return dist
