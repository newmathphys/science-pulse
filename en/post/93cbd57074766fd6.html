Hoare: quicksort and divide-and-conquer

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ T(n) = 2T(n/2) + O(n) \Rightarrow T(n) = O(n \log n) \]

Code

def quicksort(items):
    # Разделяй и властвуй (Хоар, 1960)
    if len(items) < 2:
        return items
    pivot = items[len(items) // 2]
    less = [x for x in items if x < pivot]
    equal = [x for x in items if x == pivot]
    greater = [x for x in items if x > pivot]
    return quicksort(less) + equal + quicksort(greater)
