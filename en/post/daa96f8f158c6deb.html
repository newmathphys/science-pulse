§ 1.2 · Computer science

Euclid: the oldest working algorithm

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ \gcd(a, b) = \gcd(b, a \bmod b), \quad T(n) = \mathcal{O}(\log n) \]

Code

def euclid_gcd(a: int, b: int) -> int:
    # 300 г. до н.э. — Александрийский канон
    while b != 0:
        a, b = b, a % b
    return a

def extended_gcd(a: int, b: int) -> tuple:
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = extended_gcd(b, a % b)
    return (g, y1, x1 - (a // b) * y1)
