§ 4.4 · Mathematics

Number theory: arithmetic of remainders

A foundational mathematics node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ a^{p-1}=1\ (\mathrm{mod}\ p), \quad a^{\varphi(n)}=1\ (\mathrm{mod}\ n) \]

Code

def mod_pow(a, e, m):
    result = 1
    while e:
        if e & 1:
            result = result * a % m
        a = a * a % m
        e >>= 1
    return result
