§ 5.3 · Computer science

Turing: the machine that defined computation

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ M = (Q, \Gamma, b, \Sigma, \delta, q_0, F), \quad \delta: Q \times \Gamma \to Q \times \Gamma \times \{L, R\} \]

Code

def turing_step(state, tape, head, delta):
    symbol = tape.get(head, 'blank')
    new_state, write, move = delta[(state, symbol)]
    tape[head] = write
    head += 1 if move == 'R' else -1
    return new_state, tape, head
