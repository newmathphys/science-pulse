§ 6.2 · Computer science

Lennard-Jones dynamics and the Lorenz attractor

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ V(r) = 4\varepsilon\left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^{6}\right] \]

Code

def lennard_jones(r: float, epsilon: float = 1.0, sigma: float = 1.0) -> float:
    sr6 = (sigma / r) ** 6
    return 4.0 * epsilon * (sr6 * sr6 - sr6)

def lorenz_step(state, dt, sigma=10.0, rho=28.0, beta=8/3):
    x, y, z = state
    return (x + dt * sigma * (y - x),
            y + dt * (x * (rho - z) - y),
            z + dt * (x * y - beta * z))
