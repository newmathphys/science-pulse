§ 6.6 · Computer science

A*: shortest path with a heuristic

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ f(n) = g(n) + h(n), \quad h(n) \leq h^{*}(n) \]

Code

import heapq

def astar(start, goal, neighbors, h):
    open_set = [(h(start), 0, start)]
    best = {start: 0}
    while open_set:
        _, g, node = heapq.heappop(open_set)
        if node == goal:
            return g
        for nxt, cost in neighbors(node):
            new_g = g + cost
            if new_g < best.get(nxt, float('inf')):
                best[nxt] = new_g
                heapq.heappush(open_set, (new_g + h(nxt), new_g, nxt))
    return None
