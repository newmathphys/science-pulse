§ 4.10 · Computer science

Graph algorithms: shortest paths

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ G=(V,E), \quad \mathrm{reachable}(u,v) \Longleftrightarrow \exists\, u \to v \]

Code

import heapq

def dijkstra(graph, start):
    dist = {start: 0}
    heap = [(0, start)]
    while heap:
        d, u = heapq.heappop(heap)
        for v, w in graph.get(u, []):
            if d + w < dist.get(v, float('inf')):
                dist[v] = d + w
                heapq.heappush(heap, (dist[v], v))
    return dist
