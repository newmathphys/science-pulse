Ada Lovelace: the first algorithm

A foundational computer science node in the Science Pulse canon. The formula, code and visual model are shown below. The full lecture is available in the Russian original.

\[ B_n \text{ через } \sum_{k=0}^{n} \binom{n+1}{k} B_k = 0 \]

Code

def bernoulli_numbers(n: int):
    # Последовательность операций (алгоритм Ады Лавлейс, 1843)
    from fractions import Fraction
    A = [Fraction(0)] * (n + 1)
    for m in range(n + 1):
        A[m] = Fraction(1, m + 1)
        for j in range(m, 0, -1):
            A[j - 1] = j * (A[j - 1] - A[j])
    return A[0]
