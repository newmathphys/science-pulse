I. Исторический контекст и постановка задачи

1929 и 1963 • Кембридж и MIT · Джон Леннард-Джонс и Эдвард Лоренц.

Ключевой вопрос: Как две простые нелинейные системы породили молекулярную динамику и науку о хаосе?

Потенциал Леннард-Джонса V(r) = 4ε[(σ/r)¹² − (σ/r)⁶] описывает притяжение и отталкивание нейтральных атомов: далёкая часть — дисперсионное притяжение ван дер Ваальса, ближняя — кулоновское вытеснение электронных облаков. Всего два параметра, а молекулярная динамика на этом потенциале воспроизводит фазовые переходы, кристаллизацию и поведение жидкостей — отдельные силовые поля для белков строятся по тем же принципам. В 1963 году Эдвард Лоренц, упрощая модель конвекции атмосферы, получил три дифференциальных уравнения, решения которых никогда не повторяются и чувствительны к начальным условиям: странный аттрактор стал символом теории хаоса. Обе системы считаются на компьютере шаг за шагом: RK4 для динамики, интегрирование по времени для траекторий, и именно вычислительная наука превратила их в инструмент прогноза погоды и проектирования материалов.

def lennard_jones(r: float, epsilon: float = 1.0, sigma: float = 1.0) -> float:
    sr6 = (sigma / r) ** 6
    return 4.0 * epsilon * (sr6 * sr6 - sr6)

def lorenz_step(state, dt, sigma=10.0, rho=28.0, beta=8/3):
    x, y, z = state
    return (x + dt * sigma * (y - x),
            y + dt * (x * (rho - z) - y),
            z + dt * (x * y - beta * z))
