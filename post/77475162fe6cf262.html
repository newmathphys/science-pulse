I. Исторический контекст и постановка задачи

1956–1959 • Амстердам · Эдсгер Дейкстра.

Ключевой вопрос: Как найти самый быстрый маршрут в графе из миллиарда дорог за доли секунды?

Дейкстра предложил алгоритм поиска кратчайших путей от одной вершины графа до всех остальных. Он использует жадную стратегию: на каждом шаге выбирается ближайшая ещё не обработанная вершина, и её расстояния фиксируются навсегда. С двоичной кучей алгоритм работает за O((V+E)log V). Этот метод стал основой навигации: маршрутизаторы интернета, карты, логистика и планировщики задач считают пути именно так. Дейкстра же сформулировал принцип структурного программирования и знаменитую фразу о том, что простота — предпосылка надёжности: сложный код почти невозможно сделать корректным.

Просветительская задача для самопроверки

Кратчайший путь A→C, если рёбра A→B = 1, B→C = 2, A→C = 5?

Подсказка: Алгоритм Дейкстры релаксирует d(v) = min(d(u) + w(u,v)).

Ответ: 3 (A→B→C, прямое ребро даёт 5). Ответ вычислен ядром точно (арифметика Python, без округлений).

Код

import heapq

def dijkstra(graph, start):
    # Кратчайшие пути от start (Дейкстра, 1959)
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    queue = [(0, start)]
    while queue:
        d, node = heapq.heappop(queue)
        if d > dist[node]:
            continue
        for neighbor, weight in graph[node]:
            if d + weight < dist[neighbor]:
                dist[neighbor] = d + weight
                heapq.heappush(queue, (dist[neighbor], neighbor))
    return dist
