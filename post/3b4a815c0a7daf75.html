I. Исторический контекст и постановка задачи

1843 г. • Лондон · Ада Лавлейс.

Ключевой вопрос: Почему первую программу написала женщина, которая предсказала компьютерную музыку?

Ада Лавлейс перевела и дополнила статью о вычислительной машине Чарльза Бэббиджа, и её примечания оказались важнее оригинала. В них она описала последовательность операций для вычисления чисел Бернулли — по сути первую программу для машины. Лавлейс первой отделила вычисления от чисел: машина может работать с любыми символами, а не только с арифметикой, и потому способна сочинять музыку и обрабатывать тексты. Она же указала границы: машина не мыслит, а лишь исполняет предписанные операции. Язык программирования Ada и медаль Лавлейс напоминают, что программирование — это отдельная наука о последовательностях операций.

Просветительская задача для самопроверки

Чему равен 4-й член последовательности чисел Бернулли B₍4₎?

Подсказка: Рекурсия: Σ C(n+1, k)·B_k = 0, начиная с B₀ = 1.

Ответ: B₍4₎ = -1/30. Ответ вычислен ядром точно (арифметика Python, без округлений).

Код

def bernoulli_numbers(n: int):
    # Последовательность операций (алгоритм Ады Лавлейс, 1843)
    from fractions import Fraction
    A = [Fraction(0)] * (n + 1)
    for m in range(n + 1):
        A[m] = Fraction(1, m + 1)
        for j in range(m, 0, -1):
            A[j - 1] = j * (A[j - 1] - A[j])
    return A[0]
