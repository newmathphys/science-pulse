I. Исторический контекст и постановка задачи

300 г. до н.э. • Александрия · Евклид («Начала», книга VII).

Ключевой вопрос: Как метод деления отрезков из «Начал» стал фундаментом RSA и современной криптографии?

Евклид описал способ нахождения наибольшего общего делителя двух целых чисел без полного перебора делителей. Ключевой шаг — замена большего числа остатком от деления: gcd(a, b) = gcd(b, a mod b). Алгоритм завершается за логарифмическое число шагов O(log min(a, b)). Расширенная версия находит коэффициенты Безу и обратный элемент по модулю. Именно она используется в каждом браузере и смартфоне при вычислении ключей RSA и TLS. Это первый в истории строго сформулированный вычислительный алгоритм, доживший до наших дней.

Просветительская задача для самопроверки

На сколько шагов больше потребуется алгоритму для входа, который в 1024 раз длиннее?

Подсказка: Логарифмическая сложность: шаги растут как log₂ размера.

Ответ: на 10 шагов больше. log₂(1024) = 10: во столько шагов укладывается рост входа.

Код

def euclid_gcd(a: int, b: int) -> int:
    # 300 г. до н.э. — Александрийский канон
    while b != 0:
        a, b = b, a % b
    return a

def extended_gcd(a: int, b: int) -> tuple:
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = extended_gcd(b, a % b)
    return (g, y1, x1 - (a // b) * y1)
