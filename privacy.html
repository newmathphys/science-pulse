Политика конфиденциальности

Science Pulse — статический научный сайт. Мы не создаём аккаунты и не собираем персональные данные на сервере.

Что хранится

  • Прогресс чтения («Моя ветка») хранится только в вашем браузере: localStorage["scm_branch_v1"].
  • Сайт размещён на GitHub Pages; GitHub может вести технические журналы по своей политике.
  • Публикация в Telegram/Threads выполняется через официальные API этих платформ; их политики применяются отдельно.

Чего мы не делаем

  • Не продаём данные.
  • Не используем рекламные трекеры.
  • Не генерируем контент LLM.
