# Карточки: студийный движок 3Blue1Brown + Typst

Документ описывает визуальный движок карточек Science Pulse: чертежи в стиле
3Blue1Brown (Manim NumberPlane), цветовое кодирование уравнения и журнальную
вёрстку через Typst, с автоматическим fallback на Pillow.

Код: `science_pulse/cards3b1b.py` (студийный движок), `science_pulse/cards.py`
(`render_card`, движок Pillow — fallback).
Тесты: `tests/test_cards3b1b.py`, `tests/test_cards.py`, `tests/test_abtest.py`.

## Как это работает

`render_card(..., engine="auto")`:

1. если установлен пакет **`typst`** — собирается студийная карточка
   (`render_studio_card`): чертёж 3B1B (matplotlib) + вёрстка Typst;
2. если Typst недоступен или сборка упала — **автоматический fallback** на
   Pillow-рендер (`render_card` из `cards.py`);
3. результат всегда PNG **1080×1080, RGB**.

Установка Typst: `pip install typst` (бинарник ~14 МБ, без LaTeX и браузера).

## Чертёж в стиле 3Blue1Brown

`render_3b1b_plot(post, out_png)` рисует `NumberPlane`:

- **нет внешней рамки** (`spines` скрыты), оси X и Y проходят **через центр (0,0)**
  со стрелками на концах;
- **двухуровневая сетка**: минорная `#151E2E` и основная `#223047` на фоне `#090C12`;
- **три математических смысла одновременно** (цветовое кодирование):
  - голубой `#58C4DD` — функция/волна,
  - мятно-зелёный `#83C167` — площадь/интеграл (столбики Римана),
  - жёлтый `#FACC15` — касательный вектор/производная,
  - коралловый `#FC6255` — экстремум/критическая точка/деградация.

### Сюжетные семейства графиков (выбор по содержанию)

Чертёж выбирается **по содержанию поста** (формула → смысл → `meta.visual_type`),
а не по дисциплине — иначе все карточки одной дисциплины совпадали бы:

| Семейство | Когда выбирается | Что рисуется |
|:--|:--|:--|
| `formula` | есть формула поста (по умолчанию) | **настоящий график `f(x)`** (безопасный SymPy-парсер), `f′(x)` и экстремум |
| `orbit` | орбита / тяготение / N-body | эллипс Кеплера: фокус, тело, вектор скорости |
| `wave` | волна / квант / интерференция | волновой пакет + фазовое поле (quiver) |
| `decay` | распад / полураспад / затухание | экспонента с отметками `T½` |
| `pendulum` | маятник / колебания | затухающие `θ(t)` и `ω(t)` |
| `heat` | диффузия / тепло / энтропия | расплывающиеся гауссианы |
| `prob` | вероятность / распределение | нормальная кривая с полосами `±σ` |
| `cells` | Game of Life / клеточный автомат | решётка живых клеток |
| `sort` | сложность / алгоритм / сортировка | `O(log N)` / `O(N log N)` / `O(N²)` |
| `graph` | граф / сеть / маршрут | узлы и связи |
| `growth` | последовательность / OEIS | ряд `a(n)` с трендом |

Если формула не парсится — работает откат: `formula → семейство дисциплины → sine`.
Проверка: `tests/test_cards3b1b.py::test_plot_family_is_content_aware`.

## Вёрстка Typst и цветовой ключ

`render_studio_card` собирает страницу 810pt (ровно 1080 px при 96 ppi):

- верхний «паспорт»: бейдж дисциплины + источник;
- крупный заголовок и lead с авто-переносами;
- чертёж в рамке;
- **блок «Аналитическое соотношение и цветовой ключ геометрии»** — **формула,
  отрисованная математическим движком** (`render_formula_image`, matplotlib
  mathtext, `stixsans`, прозрачный фон) плюс трёхсекционная легенда: каждый цвет
  на чертеже подписан словами того же цвета (метод Stuart Riffle / 3Blue1Brown);
- подвал со ссылкой на канал.

Спецсимволы Typst экранируются (`_esc_typst`), inline-математика из заголовка
снимается (`_strip_inline_math`), поэтому сборка не падает на `$`, `#`, `_`.

> **Почему формула — картинка.** Строка `$\int_a^b f(x)\,dx$`, вставленная как
> текст, выглядит сломанной (видны `$` и `\`). Поэтому формула рендерится
> отдельным PNG (настоящие многоэтажные дроби, интегралы, индексы) и
> вставляется в Typst во всю ширину блока (`width: 82%`). Если LaTeX невалиден,
> используется Unicode-фоллбэк (`formula_to_unicode`).

> **Чертёж по данным поста.** Для математики карточка «умная»: если в заголовке
> или lead найдена числовая последовательность (`0,1,1,2,3,5,8,…`, OEIS), на
> чертёж выносится именно её профиль в лог-шкале (тренд — прямая ⇒
> экспоненциальный/рекуррентный рост). Служебные «хвосты» вида `…,1?`
> отбрасываются, чтобы не рисовать ложную точку.

## Использование

```bash
# студийный движок включён автоматически, если установлен typst
./run.sh site                      # сайт/карточки через .venv (там typst)
.venv/bin/python -m science_pulse.cli publish --dry-run
```

Явные режимы: `render_card(post, engine="auto"|"typst")`. Pillow-рендер
принудительно — `engine="pillow"` (движок без Typst).

## Обновление вышедших карточек (`recard`)

После доработки движка карточки уже опубликованных постов можно заменить, **не
меняя `message_id`** (подпись сохраняется) — через `editMessageMedia`:

```bash
./run.sh recard --dry-run          # только перерисовать в data/cards/
./run.sh recard                    # перерисовать и заменить в канале
./run.sh recard --post-id <id>     # только конкретные посты
```

Команда берёт успешные публикации Telegram, рендерит карточку текущим движком,
собирает ту же подпись (`build_caption`) и обновляет фото; в БД пишутся новый
`card_path` и `card_file_id`. Ответы Telegram разбираются честно:

- `message to edit not found` — сообщение удалено в канале вручную ⇒ пост
  числится опубликованным ошибочно; вернуть его в очередь можно через
  `Storage.forget_publication(post_id, "telegram")` + `status='ready'`;
- `message is not modified` — карточка байт-в-байт совпала (например, у поста
  нет формулы), менять нечего.

## Ограничения

- Без установленного `typst` используется Pillow-рендер (прежний вид).
- Студийный движок требует `matplotlib` (уже в зависимостях).
- Шрифты: используются DejaVu/Liberation (есть в системе и matplotlib).
- Формула рендерится matplotlib mathtext (`stixsans`), а не TeX-движком Typst:
  поддержано большинство конструкций LaTeX; экзотика (`\begin{cases}` и т.п.)
  уйдёт в Unicode-фоллбэк.
