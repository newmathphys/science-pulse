# Explainer-фильм: инфографика в стиле «Закон Амдала»

`science_pulse/explainer_film.py` — чистый Python-движок динамической
инфографики. Без видео-нейросетей, без LLM, без платных API.

## Что делает

Берёт обычный `Post` и собирает MP4 `9:16` или `1:1`:

1. **HUD:** тёмно-синий чертёжный фон `#0B1021`, сетка, окружности,
   прогресс-бар `#EAB308`, номер сцены и множитель справа.
2. **Сцена 1 — парадокс:** заголовок, крючок, 10 блоков шагов, оранжевая
   последовательная часть, синяя параллельная, стрелка к узкому месту.
3. **Сцена 2 — паспорт:** учёный, год, карточка первоисточника.
4. **Сцена 3 — формула:** формула поста, 10 блоков, бегущий жёлтый счётчик
   `×1,5 → ×3,3` (значения из формулы/чисел поста).
5. **Сцена 4 — waffle-grid 5×8:** 40 ячеек, жёлтые «узкие» ячейки сжимаются,
   счётчик `40 Ч → 28,3 Ч`.
6. **Сцена 5 — вывод:** столбцы, `+%`, три короткие строки.
7. **Караоке-субтитры:** 2–3 слова капсом, текущее слово — на цветной плашке
   `#1D4ED8`; таймкоды из `voice.py` (edge/piper) или приблизительные.

## Команды

```bash
./sp film --style explainer --post-id <id> --aspect 9:16
./sp film --style explainer --post-id <id> --aspect 1:1 --send
```

Пульт:

```text
/film explainer <id> 9:16
/film explainer <id> 1:1
```

## Данные

| Что | Откуда |
|:--|:--|
| заголовок, крючок, тело | `Post` |
| формула | `formula_plain` / `formula_latex` |
| учёный, эпоха | `meta["scientist"]`, `meta["era"]` |
| первоисточник | `source_name`, `source_url` |
| применение | `meta["modern_application"]` |
| голос и таймкоды | `voice.film_voice_for_post()` |

## Кэш и реестр

- MP4: `data/explainer_films/<id>_<aspect>.mp4`
- ключ: `data/explainer_films/<id>_<aspect>.key`
- реестр: `data/video_registry.json` (`./sp videos`)

Реестр фиксирует `style`, `aspect`, `path`, размер, sha256, время, движок.
Это позволяет видеть, какие ролики менялись со временем.

## Настройки

```yaml
explainer:
  aspect: "9:16"
  width: 1080
  height: 1920
  fps: 24
  max_frames: 2400
```

## Ограничения

- Это программная инфографика, не «кинематографический» 3D.
- Для идеального совпадения с референсом нужны ручная типографика и
  дополнительные сцены; текущий движок покрывает механику: HUD, счётчик,
  waffle-grid, караоке.
- Формулы отображаются Unicode-текстом, без LaTeX-рендера в каждом кадре.
