# Радар мировых новостей (Trending Radar)

Модуль `science_pulse/trending.py` ищет **самые популярные прямо сейчас** научные
материалы в открытых источниках (без ключей и регистрации), считает «индекс
горячести» и отдаёт Топ-5 оператору в Пульт.

## Источники

| Источник | Что даёт | Метрики |
|:--|:--|:--|
| **Hacker News** (`hacker-news.firebaseio.com`) | `topstories` → `item` | `score` (лайки), `descendants` (комментарии), `time` |
| **GitHub Search API** (`api.github.com`) | свежие репозитории со звёздами | `stargazers_count` (⭐ ≈ лайки), `forks_count`, `created_at` |
| **Reddit** (`r/math`, `r/physics`, `r/compsci` `/hot.json`) | горячие посты | `ups`, `num_comments`, `created_utc` |

> ⚠️ **Про Reddit.** Reddit отдаёт `403 Blocked` с серверных/датацентровых IP
> (в т.ч. из GitHub Actions). Это не ошибка кода: источник помечен как
> «best-effort», и радар спокойно работает на Hacker News + GitHub. Для Reddit
> нужен OAuth-токен — это отдельный шаг.

## Индекс горячести

Гравитационная формула виральности: свежее и залайканное ценится выше.

```
heat = (likes + 2 * comments) / (hours + 2) ** 1.4
```

* `hours` — сколько часов прошло с публикации;
* множитель `2` у комментариев — обсуждение важнее пассивного лайка;
* степень `1.4` — «остывание» новости со временем.

## Научный фильтр

Ключевые слова разбиты по дисциплинам (`KEYWORDS` в `trending.py`). Для каждого
материала считается `relevance` (сколько ключевых слов найдено) и `domain`
(`math` / `physics` / `cs`, по умолчанию `cs`).

Сортировка: **сначала релевантные** (`relevance > 0`), затем по `heat`. Так
радар не отдаёт пустой список в «скучный» день, но научные хиты всегда впереди.

## Команды

```bash
python -m science_pulse.cli trending                 # Топ-5 на русском
python -m science_pulse.cli trending --domain physics --top 3
python -m science_pulse.cli trending --json          # машинный вывод
python -m science_pulse.cli trending --no-translate  # быстрее, без перевода
```

В Пульте Telegram:

* **`/trending [math|physics|cs]`** — Топ-5 с лайками 👍, комментариями 💬 и 🔥;
* **`/pick N`** — взять хит №N в очередь с максимальным приоритетом (`quality = 100`);
* **`/pick N now`** — сразу отрисовать карточку и опубликовать внеочередным постом.

Кандидаты кэшируются в `kv` под ключом `trending_candidates` (JSON), поэтому
`/pick` работает и после перезапуска бота.

## Приоритет очереди

`/pick` ставит `quality = 100`, а `/skip` понижает приоритет до `0.01`.
Очередь выбирает пост по `ORDER BY quality DESC, created_at ASC` — поэтому
«выбранный хит» выходит первым, а «отложенный» уезжает в конец.

> Нюанс: `Post.from_row` читает `quality or 0.5`, поэтому «полный ноль»
> использовать нельзя — он вернётся как `0.5`. Для отложенного поста берём `0.01`.

## Ограничения

* Перевод заголовков идёт через ту же цепочку, что и посты (gtx → MyMemory →
  deep-translator) и может упираться в лимиты — тогда заголовок остаётся на языке
  оригинала.
* Радар не «редактор»: он показывает популярность, а решение публиковать
  принимает оператор (`/pick`).
