# SCM в экосистеме

SCM — **публицистическая и коммерческая ветка** научной экосистемы. Она не
заменяет ядро и не переписывает чужие проекты.

## 1. Карта

```text
Рукописи / теория
      │
      ▼
РИИ + RII Lab + NYUUI + PTE     ← научное основание, знания, истина
      │
      ├── KERN                  ← ворота верификации кода (e=1)
      ├── AI Connector          ← модельный орган (черновики, перевод)
      ├── Эмбрион-Симбиот       ← операторский экзокортекс
      │
      ▼
   SCM (Science Pulse)
      ├── научная ветка: источники, формулы, задачи
      ├── публицистическая: посты, карточки, фильмы, сайт
      ├── коммерческая: аудитория → продукт → деньги
      └── языковая: регистры науки/лекции/поста/оффера
```

## 2. Кто чем владеет

| Система | Владеет | SCM читает | SCM пишет |
|:--|:--|:--|:--|
| RII | ядро решений, facts/effects | `rii_probe_fact`, `rii_circuit_ask` | нет |
| RII Lab | MVP RII-001, Z3/Lean | отчёты, сертификаты | нет |
| KERN | верификация кода | `e=1`/`e=0` | нет |
| NYUUI | корпус, FTS5, граф, PTE | `campus_search`, `campus_truth` | только `write_note` (unproven) |
| AI Connector | модели, `/v1/capability` | черновики/перевод | нет |
| Эмбрион | голос, зрение, действия | read-only | нет |
| **SCM** | посты, публикации, метрики, Knowledge Base | — | **свои** данные |

## 3. Границы

1. SCM не импортирует код RII/NYUUI/KERN/Эмбриона напрямую.
2. Связь — только через документированные интерфейсы (MCP/HTTP/CLI).
3. Секреты и чужие базы не копируются.
4. Оракул ставит `PROVEN`; SCM только фиксирует вердикт и источник.
5. Коммерческая ветка не меняет научный статус факта.

## 4. Полезные внешние точки

| Точка | Назначение |
|:--|:--|
| `rii_probe_fact` | точный факт из индексов РИИ |
| `rii_circuit_ask` | ответ с источником/уверенностью |
| `rii_capability_check` | не повторять опровергнутые пути |
| `campus_search` | поиск по корпусу NYUUI |
| `campus_truth` | что доказано по `e=1` |
| `kernc` / KERN bridge | проверка инвариантов кода |
| `AI Connector /v1/capability` | черновик/перевод, не истина |

## 5. Разрывы, которые SCM не чинит в одиночку

- NYUUI MCP не зарегистрирован в клиенте;
- AI Connector может быть не запущен на `127.0.0.1:8080`;
- Z3 может отсутствовать в `PATH`;
- секреты лежат в открытых файлах вне SCM.

Это задачи владельца экосистемы, а не изменение чужих репозиториев из SCM.
