# Ветки пользователей, форки и академические плашки

Сайт SCM — не архив, а интерактивная среда. Всё работает статически на
GitHub Pages, прогресс хранится в `localStorage`, без сервера и аккаунтов.

## 1. Личная ветка освоения

На главной и на каждой странице параграфа есть панель:

```text
🌿 Моя ветка освоения науки
📐 Математика     [====----] 4 / 20
💻 Информатика    [==------] 2 / 9
⚛️ Физика         [===-----] 3 / 12
Следующие шаги: § 2.1 · …   § 1.2 · …
```

- ключ: `localStorage["scm_branch_v1"]`;
- кнопка `✓ Отметить параграф освоенным` на странице поста;
- прогресс и рекомендации пересчитываются локально;
- сервер не нужен.

## 2. Форки экспериментов `#fork=...`

В песочнице каждого поста:

```text
🌿 Скопировать ссылку на мою ветку
```

Ссылка получает хэш:

```text
/post/<id>.html#fork=A_k_x
```

При открытии ссылки ползунки `A`, `k` и поле `x` выставляются в эти значения,
и график сразу перерисовывается. Читатель может делиться конфигурацией в
комментариях Telegram.

## 3. Академические плашки `[LATEX] [PYTHON] [BIBTEX] [ЗАДАЧА]`

На странице параграфа под заголовком:

- `[АННОТАЦИЯ]` — краткий смысл;
- `[LATEX]` — исходная формула;
- `[PYTHON]` — код алгоритма, если есть;
- `[BIBTEX]` — готовая запись для цитирования;
- `[ЗАДАЧА]` — задача самопроверки с ответом.

Всё раскрывается без перезагрузки, в духе академического шаблона `al-folio`.

## 4. Недельный отбор видео `/ab`

Воскресный ритуал `weekly_ab`:

- берёт рейтинг дизайнов из бандита Томпсона (`themes.win_rates`);
- выбирает победителя недели;
- отправляет отчёт в админ-чат;
- даёт победителю дополнительный вес на следующую неделю.

Ручное переключение: `/theme <имя>` или `/film book`.

## 5. Ограничения

- Прогресс привязан к браузеру (`localStorage`), не к аккаунту.
- Ссылка `#fork=...` не синхронизируется с сервером.
- Задача в постах канала выключена (`challenge_every_nth: 0`), на сайте
  плашка `[ЗАДАЧА]` остаётся.
