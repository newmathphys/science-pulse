# 📻 Science Pulse FM — научное радио 24/7

Бессерверная радиостанция проекта: генеративный математический эмбиент и
лекции о законах природы. Работает **без внешних серверов, без ключей и без
LLM** — весь звук синтезируется в браузере слушателя.

## Четыре контура

| Контур | Артефакт | Что делает |
|:--|:--|:--|
| 1. Веб-радио | `dist/radio.html` | `WebAudio API`: дрон в пифагорейском строе (220/330/440 Гц) + `BiquadFilterNode` с медленной модуляцией; ротация лекций диктора с 5-секундными музыкальными паузами; `navigator.mediaSession` (эфир продолжается на заблокированном экране смартфона); `AnalyserNode` рисует живую осциллограмму на Canvas |
| 2. Подкаст | `dist/podcast.xml` | RSS 2.0 с `itunes:*` и `enclosure` — подписка в Apple Podcasts, Яндекс.Музыке, Pocket Casts |
| 3. Радио-микс | `dist/radio_mix.mp4` + `dist/radio_chapters.txt` | сквозной микс из видео-аудиограмм опубликованных параграфов с гармоническими интерлюдиями (ffmpeg) и оглавлением таймкодов для YouTube |
| 4. Прямой эфир | `cli radio --rtmp <URL>` | `ffmpeg -re -stream_loop -1 … -f flv` — круглосуточное вещание в Telegram Live / YouTube Live |

## Синхронизация по «часам Вселенной»

Эфир детерминирован и одинаков у всех слушателей:

```
epoch_slot_index() = (now − 2026-01-01T00:00:00Z) // 6 ч
эфирный выпуск     = playlist[epoch_slot_index() mod len(playlist)]
```

Плеер на любом устройстве мгновенно попадает на тот же такт расписания, что и
остальные — база и сервер для этого не нужны.

## Эфирная сетка

`radio_playlist()` собирает выпуски в порядке §-номеров: сначала открытые
(`published`), затем подготовленные узлы канона (`ready`, «⏳ Готовится к
эфиру»). Для каждого выпуска берётся 5-блочный лекционный сценарий
(`voice.build_lecture_script`), поэтому даже параграф без готового `.mp3`
звучит — браузер произносит сценарий через `speechSynthesis` поверх
математического дрона.

## Команды

```bash
python -m science_pulse.cli radio              # страница + подкаст + сводка эфира
python -m science_pulse.cli radio --json       # машиночитаемый отчёт
python -m science_pulse.cli radio --mix        # сквозной микс (ffmpeg) + таймкоды
python -m science_pulse.cli radio --rtmp rtmps://dc4.rtmp.t.me/s/KEY --run
```

В Пульте: `/radio` — состояние эфира и ссылки.

## Гарантии

* Сайт собирается без радио, если что-то пошло не так: `_write_radio` ловит
  исключения и не роняет сборку.
* Микс не собирается, если нет `ffmpeg` или нет ни одной видео-аудиограммы
  (`build_radio_mix` → `None`).
* Тесты `tests/test_radio.py` полностью герметичны: сеть не вызывается,
  RTMP-команда только формируется (`rtmp_argv`), не запускается.
