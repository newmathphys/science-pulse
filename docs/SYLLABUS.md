# ♾️ Бесконечный поток: матрица курса, краулер и родословная

60 узлов канона (`§ 1.1 … § 6.x`) — это **корневое семя**, а не потолок.
Дальше система растёт по трём эшелонам.

## Эшелон 2: матрица университетского курса (`syllabus_tree.py`)

**45 магистральных ветвей × 3 темы = 135 тем**, идущих сразу за каноном и
получающих сквозные §-номера `§ 11.1 … § 55.3`:

* ступени 11–25 — **математика**: арифметика и простые числа → геометрия →
  алгебра → аналитическая геометрия → линейная алгебра и тензоры → пределы и
  ряды → производная → интеграл и векторный анализ → ОДУ → УЧП → комплексный
  анализ → Фурье и Лаплас → теория вероятностей → дискретная математика и
  графы → абстрактная алгебра, топология, спецфункции;
* ступени 26–40 — **физика**: кинематика → динамика → статика и гидростатика →
  тяготение и Кеплер → колебания и волны → МКТ → термодинамика →
  статистическая физика → электростатика → магнетизм и Максвелл → оптика →
  СТО/ОТО → атомные спектры → квантовая механика → твёрдое тело, ядро,
  астрофизика;
* ступени 41–55 — **информатика**: булева алгебра → архитектура процессоров →
  линейные структуры → хеширование → сортировка → деревья → графы →
  ДП → строки и автоматы → компиляторы → вычислимость и Гёдель → теория
  информации → криптография → ОС, БД, сети → распределённые системы, БПФ, ИИ.

Каждая тема несёт формулу (LaTeX), учёного, крючок-вопрос и пререквизит:
первая тема ветви ссылается на узел канона, остальные — на предыдущий
параграф, поэтому причинная цепочка (`prereq_ids`) непрерывна.

```python
from science_pulse.syllabus_tree import syllabus_summary, next_syllabus_topics, find_topic
syllabus_summary()   # {"branches": 45, "topics": 135, "first_section": "11.1", "last_section": "55.3"}
find_topic("11.2")   # {"title": "Бесконечность простых чисел", …}
```

## Эшелон 3: «источники источников» (`sources/curriculum_crawler.py`)

`RecursiveMetaCrawler` ходит по мета-каталогам вглубь и вширь:

| Метод | Что вытягивает |
|:--|:--|
| `subcategories(category, depth)` | дерево подкатегорий (`cmtype=subcat`) — категория рождает подкатегории, те — тысячи статей |
| `category_members(category)` | статьи категории (`cmtype=page`) |
| `article_links(title)` | внутренние ссылки статьи (`prop=links`) — «См. также» и библиография |
| `oeis_xref(series)` | перекрёстные ссылки OEIS (`xref` → соседние `Axxxxxx`) |
| `discover(categories, depth)` | кандидаты новых тем по ступеням A/B/C (`CATEGORY_TIERS`) |

Сеть подключается **только** через инъектируемый `http_get`: без него модуль
возвращает пустые списки и полностью герметичен (тесты не ходят в сеть).

`CurriculumCrawlerSource` (источник `curriculum`, вес 40) превращает темы
матрицы в посты очереди: §-номер, `complexity_tier = ступень`,
`prereq_ids`, учёный, эпоха, формула, `syllabus_branch`.

## Родословная первоисточников (`enricher.build_source_lineage`)

Википедия — вторичный проводник. Для каждого параграфа строится три уровня:

1. **📜 Первоисточник** — оригинальный труд: «Евклид, "Начала", Книга VII»,
   «И. Ньютон, "Математические начала натуральной философии" (1687)»,
   «К. Шеннон, "Математическая теория связи" (1948)» (`PRIMARY_WORKS`, 30 узлов);
2. **🏛 Академический свод** — верификатор по дисциплине: NIST DLMF и Lean 4
   Mathlib (математика), NIST CODATA и PDG (физика), OEIS и Rosetta Code (CS);
3. **🌐 Цифровой узел и библиография** — API-источник + ссылки из разделов
   «Литература» / «Примечания» полной статьи.

Родословная печатается в лонгриде (`lineage_line`), в паспорте главы на сайте
и в первом блоке радио-лекции.

## Глубина текста

`enrich_post_longread` запрашивает у MediaWiki **полную статью одним запросом**
(`action=query&prop=extracts|revisions&rvprop=content`, без `exintro`),
извлекает формулы `<math>…</math>` из викитекста и собирает пять разделов:
историю (до 2 600 знаков энциклопедии), аналитическую модель с формулами
первоисточника, вычислительную верификацию, связи в дереве с родословной и
инженерное применение XXI века.

## Развёрнутый атлас

Сборка сайта создаёт полноценные главы **для всех 60 узлов канона сразу**:
открытые (`published`) помечаются «✓ Открыто», подготовленные (`ready`) —
«⏳ В очереди эфира». Каждая глава содержит переключатель пяти слоёв глубины
`z = 0…4`, интерактивную песочницу с кнопками WebAudio и экспорта SVG, а также
блок «📜 Родословная первоисточников».
