# Лабораторные стенды (`simulate.py`)

Шесть вычислительных стендов на встроенных движках `numpy` и `scipy`
(`scipy.signal`, `scipy.spatial`, `scipy.sparse`) — без ключей, без сети и без
внешних данных. Каждый стенд даёт и числовой результат (для тестов), и диптих
для карточки (`cards_academic._chart_diptych`).

| Стенд (`meta["simulation"]`) | Что считает | Формула / метод |
|:--|:--|:--|
| `cern_dimuon` | инвариантная масса димюонов, пик Z-бозона из фона | `M = √((E₁+E₂)² − |p₁+p₂|²)`, Брейт — Вигнер |
| `ligo_chirp` | чирп слияния чёрных дыр + фильтр + спектрограмма + звук | `h(t) = A(t)cos Φ(t)`, Баттерворт 4-го порядка |
| `voronoi_laplacian` | сетка Вороного—Делоне и спектр лапласиана графа | `L = D − A`, число Фидлера λ₂ |
| `sat_tsp` | фазовый переход 3-SAT и маршрут коммивояжёра | `α = m/n ≈ 4.26`, DPLL, 2-opt |
| `sparse_cg` | структура CSR и сходимость CG против градиентного спуска | `‖Ax−b‖₂`, сопряжённые градиенты |
| `seismic_ps` | триангуляция эпицентра по P/S-волнам | `d = Δt·v_P·v_S/(v_P − v_S)` |

## Числа (детерминированные, seed фиксирован)

- **CERN**: пик `90.6 ГэВ` при истинных `91.19 ГэВ` (Γ = 2.5 ГэВ), ~7200 событий.
- **LIGO**: частота `35 → 250 Гц` монотонно; масса чирпа `28.1 M⊙` (36 + 29 M⊙);
  спектрограмма показывает разгон частоты; звук в `sound.py` — доминирующая
  частота `36 → 164 Гц` (проверено тестом через БПФ).
- **Вороной/Делоне**: 26 точек, 68 рёбер, `λ₂ = 1.042` (связность сети).
- **3-SAT**: выполнимость `1.00 → 0.00` при росте α; пик усилий DPLL у порога
  (при n = 11 конечный размер сдвигает пик вправо — ожидаемый эффект).
- **TSP**: 14 городов, жадный обход `3.79` → после 2-opt `3.71` (−1.96 %).
- **CG**: `nnz = 598` при 200×200 (плотность 1.49 %), невязка `1.4·10² → 0`.
- **P/S**: Δt = 10 с → 84 км (при `v_P = 6`, `v_S = 3.5` км/с).

## Звук чирпа

`sound.sonify` для поста с `meta["simulation"] == "ligo_chirp"` синтезирует
акустический чирп слияния (35 → 250 Гц) вместо обычной гармонической
сонификации — это тот самый «взлет» частоты, который слышно на записях LIGO.

## Живые данные (пункт 6)

`live_sensors.py` дополнен:

- **P/S-триангуляция**: для станции над эпицентром путь ≈ глубине очага,
  поэтому `Δt = d·(1/v_S − 1/v_P)`; на живом событии USGS (глубина 17.7 км)
  получилось `Δt = 2.11 с`, `d ≈ 17.7 км`.
- **Вектор Bz**: читается из NOAA `products/solar-wind/mag-1-day.json`
  (берётся последняя непустая строка). Если эндпоинт недоступен, `Bz` просто
  не показывается — публикация не ломается.

## Ограничения

- 3-SAT и TSP решаются малыми размерами (n ≈ 11–14) — это демонстрация
  качественного поведения, а не бенчмарк.
- `cern_dimuon` — синтетический спектр (фон + резонанс), а не выгрузка коллайдера.
- Живые эндпоинты могут быть недоступны: срабатывает офлайн-фоллбэк.
