# Перевод контента (без LLM)

Документ описывает опциональный перевод материалов на русский: как он
включается, какие провайдеры используются, как защищаются формулы и код и как
система деградирует без зависимостей и сети.

Код: `science_pulse/text.py` (`translate_text`, `translate_preserving_latex`,
`mask_protected`, `unmask_protected`, `_looks_russian`, `_translate_chunks`),
`science_pulse/sources/base.py` (`Source._translate`).

## Принцип

Перевод — единственное место, где допускается внешний сервис. LLM не
используется. Если перевод недоступен, пост выходит в оригинале — публикация
никогда не блокируется переводом.

## Включение

`.env` / переменная окружения:

```bash
SP_TRANSLATE=1
```

или в `config.yaml`:

```yaml
translate: true
```

`SP_TRANSLATE` переопределяет значение из конфига (см. `load_config`).

Зависимость (опциональная): `deep-translator` (уже в `requirements.txt`).

## Провайдеры и порядок

`translate_text(text, target="ru", source="en")` — эшелоны:

1. Если текст уже похож на русский (`_looks_russian`: доля кириллицы > 0.35) —
   возвращается как есть, без обращения к сети.
2. **gtx** — JSON-эндпоинт Google
   (`translate.googleapis.com/translate_a/single?client=gtx`), на стандартной
   библиотеке (`urllib`), **без `deep-translator`** и без лимита слов. Защищён
   троттлингом (0.7 с между запросами) и backoff; при упорном HTTP 429 уходит
   в «карантин» на 5 минут, чтобы не тормозить пакетную обработку.
3. **MyMemory HTTP** (`api.mymemory.translated.net`) — без зависимостей,
   ~1000 слов/сутки без ключа.
4. **deep-translator** — `GoogleTranslator`, затем `MyMemoryTranslator`
   (если пакет установлен).
5. Если всё недоступно — возвращается исходный текст.

Функции `translate_via_gtx` и `translate_via_mymemory` самостоятельны и
работают в **системном Python без pip-пакетов**.

Нарезка `_translate_chunks` режет по границам предложений, длинные
предложения — по словам, чтобы не рвать смысл и не превышать лимит провайдера.

## Защита формул и кода

`translate_preserving_latex`:

1. `mask_protected` заменяет защищённые фрагменты на маркеры `ZZZP{i}ZZZ`;
2. переводится только обычный текст;
3. `unmask_protected` возвращает фрагменты на место.

Защищаются (регулярка `PROTECTED_RE`):

- блоки кода ```` ```…``` ````;
- display-формулы `$$…$$`, `\[…\]`, `\(…\)`;
- inline-формулы `$…$`;
- инлайн-код `` `…` ``.

## Где применяется

Перевод встроен в базовый источник (`Source._translate`) и вызывается в
адаптерах, возвращающих англоязычные тексты:

| Источник | Переводит |
|:--|:--|
| arXiv | заголовок, хук, аннотацию |
| GitHub raw | заголовок, тело, хук |
| Wikipedia | заголовок, описание, извлечение |
| Stack Exchange | заголовок, тело |
| Rosetta Code | заголовок, вступление, хук |
| OEIS | название последовательности, хук |
| Numbers API | заголовок, хук, тело |

Офлайн-бункер и `history_canon` — русскоязычные, перевод не нужен.

## Перевод уже лежащих постов

Если посты были собраны без перевода, их можно до-перевести:

```bash
python -m science_pulse.cli retranslate              # по умолчанию status=ready
python -m science_pulse.cli retranslate --dry-run    # показать, что переведётся
python -m science_pulse.cli drop --english --yes     # удалить непереведённые
```

`retranslate` проходит по постам, переводит `title`/`hook`/`body`
(`translate_preserving_latex`, формулы сохраняются) и обновляет записи в БД.

## Нюансы

- **Никакого перевода формул:** LaTeX и код экранируются маркерами и
  восстанавливаются дословно — важно для корректного рендера KaTeX.
- **Идемпотентность дедупликации:** перевод применяется **до** записи в БД,
  поэтому `SimHash`/отпечаток считаются по итоговому (русскому) тексту.
- **Сеть не обязательна:** без сети или без пакета поведение — «выход в
  оригинале», ошибок нет.
- **Стоимость:** провайдеры бесплатные и без ключей; лимиты Google/MyMemory
  могут throttlить при массовой добыче — тогда часть постов останется в
  оригинале (это не ошибка).
- **Провайдер по факту (проверено вживую 2026-11-02):** бесплатные эндпоинты
  Google (`gtx` и HTML-скрейпер `deep-translator`) под нагрузкой отдают
  `429 Too Many Requests` (блок по IP/квоте) — поэтому в цепочке есть
  **MyMemory HTTP** и «карантин» для gtx. MyMemory без ключа ограничен
  (~1000 слов/сутки), поэтому при массовой добыче часть постов может остаться
  в оригинале — это штатная деградация, не ошибка. Проверка:
  `translate_via_gtx("The derivative is the slope...")` →
  «Производная — наклон касательной».
- **Зависимость обязательна для перевода:** если `deep-translator` не
  установлен, `translate_text` молча возвращает оригинал (посты выходят на
  языке источника). Установка: `pip install deep-translator` (есть в
  `requirements.txt`); при системном Python без `pip` — используйте venv
  (см. README): `python3 -m venv --system-site-packages .venv &&
  .venv/bin/pip install deep-translator`, далее запускайте CLI через
  `.venv/bin/python`.
- **CI:** в GitHub Actions перевод включается секретом/переменной
  `SP_TRANSLATE=1`; `deep-translator` уже в `requirements.txt`.

## Проверка

```bash
SP_TRANSLATE=1 python -m science_pulse.cli harvest --limit 1
python -m science_pulse.cli status
```

Без сети проверяйте через тесты (перевод не делает сетевых вызовов в тестах):

```bash
python -m unittest tests.test_text -v
```
