# 🧠 Детерминированное ядро (`science_pulse/kernel.py`)

`SciencePulseKernel` сводит все подсистемы проекта в **один предсказуемый
6-фазный цикл**. В рантайме нет «болтливых ИИ-агентов»: конечный автомат,
детерминированные источники и проверяемые инварианты.

```
ФАЗА 1 canon     → 30 узлов канона в базе + насос тем курса (§ 11.1 … § 55.3)
ФАЗА 2 selection → выбор по блоку Каданова и часам эпохи, лонгрид, вычислительный паспорт
ФАЗА 3 script    → 5-блочный лекционный сценарий + двухслойный звук
ФАЗА 4 gate      → CanonGate Pass 1/2, warm staging N+1
ФАЗА 5 atlas     → все главы канона, Диск Пуанкаре, Вечное Радио, подкаст
ФАЗА 6 telemetry → метрики, INV-1…INV-8, формальная печать Lean
```

## Гарантии изоляции

* каждая фаза оборачивается в `_safe()`: исключение не роняет цикл, а
  попадает в отчёт как `{"ok": false, "error": "…"}`;
* фаза `gate` при `publish=False` **не мутирует** состояние: она лишь сообщает
  готовность карточки. Приёмка Pass 2 запускается только при реальной
  публикации (`publish=True`);
* `phase_atlas(rebuild=False)` ничего не пересобирает — удобно для проверок.

## Часы эпохи и слот

```python
epoch_slot_index()          # (now − 2026-01-01T00:00:00Z) // 6 ч
current_slot()              # {"slot": "17:00", "layer": 2, "domain": "physics", …}
```

Слот выбирается по номеру такта эпохи, поэтому расписание воспроизводимо на
любой машине и не зависит от локального времени.

## Команды

```bash
python -m science_pulse.cli kernel                # паспорт состояния (человекочитаемо)
python -m science_pulse.cli kernel --json         # тот же паспорт машиночитаемо
python -m science_pulse.cli kernel --tick         # полный 6-фазный цикл
python -m science_pulse.cli kernel --tick --publish --voice --formal
python -m science_pulse.cli expand --count 30     # добрать темы курса в очередь
```

В Пульте: `/kernel` — паспорт состояния.

## Паспорт состояния

`status_report()` возвращает: покрытие канона, размер матрицы курса, очередь
(`ready` / `published` / `failed` / `staged_next` / курсор курса), сводку
эфира радио, результат `INV-1…INV-8` и признак паузы.

`format_status()` печатает это компактно:

```
🧠 ЯДРО SCIENCE PULSE
  Фаз цикла: 6 (canon, selection, script, gate, atlas, telemetry)
  Такт эпохи: № 1230 · слот 17:00 · дисциплина physics
  Канон: 30/30 в базе, открыто 3
  Курс: 45 ветвей, 135 тем (§ 11.1 … § 55.3)
  Очередь: ready 27 · published 3 · failed 0
  Радио: 30 выпусков (с озвучкой 4), в эфире: § 1.1 • Пифагор…
  Инварианты: ✅ OK (7 проверок)
```

## Тесты

`tests/test_kernel.py` работает на герметичном стенде (`StubPipeline`):
сеть не вызывается, сайт не собирается, вместо этого проверяются порядок
фаз, изоляция ошибок, наполнение канона и насос курса.
