# 🧠 Просветительская задача (`science_pulse/challenge.py`)

Задача/тренажёр сейчас **не выводится в постах** (`challenge_every_nth: 0`).
На сайте блок самопроверки остаётся. Когда появится аудитория, задачу можно
включать раз в месяц или вручную.

Когда включена, задача требует применить формулу с картинки «в уме», а ядро
заранее считает точный ответ, чтобы подписчик мог проверить себя на тренажёре
сайта.

Мы **не копируем статьи** и **не выдумываем числа**: внешние базы дают сырьё
(формула, ряд, константа, алгоритм, имя учёного), а задачу и ответ строит
детерминированный вычислительный контур.

## Четыре стратегии (выбор детерминирован по `sha1(id)`)

| Стратегия | Когда применяется | Пример вопроса и ответа |
|:--|:--|:--|
| `steps` / `growth` | только `cs` + явная оценка сложности (`O(`, `T(n)`, `log`) | «Сколько сравнений сделает бинарный поиск для 4096 элементов?» → `12 сравнений` |
| `ratio` | формула — **доказанный** степенной закон `k·xⁿ` | «Если увеличить r в 3 раза, во сколько раз ослабнет F?» → `F ослабнет в 9 раз` |
| `substitute` | есть символ-выход и входы | «Чему равна p при x = 3?» → `p = 0.05399` |
| `solve` | уравнение без «голого» выхода (`a² + b² = c²`) | «Чему равна c, если a = 3, b = 4?» → `c = 5` |
| `concept` | формула непарсируема (`∇`, `∫`, `∑`, `mod`) | вопрос из собственного крючка выпуска |

## Как гарантируется корректность

1. **Разбор уравнения**: формула режется на отдельные отношения вне скобок
   (`•`, `⇒`, `;`, `,`), определяется символ-выход (`F`, `r_s`, `Δφ`, `s(t)`),
   а входы — только независимые параметры.
2. **Строгая нормализация**: типографика (`²`, `·`, `√`, `−`, `½`) переводится
   в арифметику; всё, где SymPy собрал бы мусор (`mod`, `lim`, `∇`, буквенные
   индексы `ₙ`), отвергается, а не «угадывается».
3. **Самопроверка вычислением**: для `ratio` ядро численно проверяет
   `f(k·x)/f(x) = k^n` в тех же точках, что и определение закона, — если
   тождество не выполняется, задача не выдаётся.
4. **Постоянные остаются постоянными**: `π` не варьируется как параметр, а
   `e^(…)` распознаётся как экспонента.
5. **Положительный корень**: для физических величин выбирается
   положительное решение уравнения.

## Куда попадает задача

| Витрина | Что видит читатель |
|:--|:--|
| Подпись поста (Telegram/Threads/Bluesky/VK/Discord/Mastodon) | **сейчас не выводится**; при `challenge_every_nth > 0` — `🧠 Задача на смекалку` |
| Глава на сайте (`post/<id>.html`, слой `z = 3`) | раскрывающийся блок «🧠 Просветительская задача для самопроверки» с подсказкой и ответом |
| Лонгрид (раздел III) | «🧠 Задача для самопроверки» и «Ответ ядра» |
| Радио и подкаст (5-й блок лекции) | только если `post_mode=interactive_challenge` |
| Пульт и ядро | задача хранится в `post.meta["challenge"]` и в вычислительном паспорте |

## Проверка

`tests/test_challenge.py` (18 тестов) проверяет не только формат, но и
**правильность ответов**:

* пифагорова тройка из ответа действительно удовлетворяет `a² + b² = c²`;
* `ratio`-ответ совпадает с `k^n`, а сам масштаб подтверждается независимым
  расчётом;
* `steps`-ответ равен `⌈log₂ N⌉` для указанного в вопросе `N`;
* для формулы с `√(2π)` подстановка использует настоящее `π`;
* физика никогда не получает «задачу про алгоритм»;
* подпись, сайт, лонгрид и лекция действительно содержат блок задачи.
