# Топология фундамента: диск Пуанкаре и INV-8

Архитектурный документ: как канон Science Pulse погружается в гиперболическое
пространство Лобачевского и какие инварианты это защищает.

Код: `science_pulse/graph.py` (метрика, координаты, геодезический маршрутизатор),
`science_pulse/sources/foundation.py` (`section_of`, `default_prereqs`),
`science_pulse/invariants.py` (INV-8).
Тесты: `tests/test_poincare.py`. Формально: `formal/Invariants.lean`
(`inv8_causal_completeness`).

## 1. Диск Пуанкаре `D = {w ∈ ℂ : |w| < 1}`

### Радиальное сжатие (ступень → радиус)

```
r(k) = tanh((k − 0.82) / 2.8)
```

| Ступень k | r(k) |
|:--|:--|
| 1 | **0.0642** |
| 2 | 0.3981 |
| 3 | 0.6519 |
| 4 | 0.8130 |
| 5 | 0.9038 |
| 6 | **0.9517** |

Сдвиг `0.82` важен: без него `r(1) = tanh(0) = 0`, и три аксиомы Ступени I
(Пифагор, Евклид, Архимед) слиплись бы в точку `(0, 0)`. Со сдвигом они
образуют правильный треугольник вокруг центра.

### Секторы симметрии ℤ₃ (дисциплина → угол)

| Дисциплина | Центр сектора θ₀ |
|:--|:--|
| `math` | `π/2` (90°) |
| `cs` | `7π/6` (210°) |
| `physics` | `11π/6` (330°) |

Внутри сектора узел со индексом `j` из `M` смещается на регулярный квант:
`θ = θ₀ + (j − (M−1)/2)·(π / 3M)`.

### Метрика

- конформный фактор: `Λ(r) = 4 / (1 − r²)²`;
- расстояние Лобачевского (кросс-отношение):

```
d_ℍ(u, v) = arcosh(1 + 2|u − v|² / ((1 − |u|²)(1 − |v|²)))
```

### Граница шага

`max_hyperbolic_jump(k)` — расстояние между точками радиусов `r(k−1)` и `r(k)`
в противоположных направлениях (наихудший случай). INV-8 требует, чтобы
фактический скачок пререквизит → узел не превышал эту границу.

## 2. Геодезический маршрутизатор

```python
find_geodesic_path(edges, coords, roots, target) -> list[str]
```

Дейкстра по гиперболической длине `d_ℍ` вдоль рёбер DAG (`prereq_ids`):
даёт маршрут наименьшего когнитивного сопротивления от корней Ступени I до
целевого узла (например, `§ 1.1 → § 2.1 → § 5.1 → § 6.6 → § 6.5`).

## 3. Инвариант INV-8 (причинно-геодезическая полнота)

Каждый узел канона ступени `k > 1` обязан:

1. иметь непустой список `prereq_ids`;
2. иметь родителя строго меньшей ступени (`tier(p) < tier(u)`);
3. иметь конечный гиперболический скачок `d_ℍ(p, u) ≤ R_max(k)`.

Нарушение переводит узел в карантин. Формальная гарантия в Lean 4:
`inv8_causal_completeness` (строгое убывание ступени ⇒ скачок ≥ 1).
