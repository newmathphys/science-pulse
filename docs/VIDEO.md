# Озвученные микро-видео: оживший чертёж + звук формулы

Модули `science_pulse/sound.py` и `science_pulse/video.py` превращают пост в
**3.6-секундный ролик со звуком**: книжная страница, на которой чертёж оживает,
а формула (или алгоритм) звучит.

## Звук (`sound.py`)

Синтез на стандартном `wave` + NumPy — без сервисов и без сети, детерминированно
(один пост → один и тот же файл).

| Домен | Что звучит |
|:--|:--|
| `math` | сложение гармоник Фурье: основной тон + обертоны |
| `physics` | частотно-модулированный волновой пакет (чирп + гауссова огибающая) |
| `cs` | шаги сортировки массива: обмены как «клики» в гармоническом строе |

Строй — пентатоника до мажор (`HARMONIC_SCALE_HZ`), мягкая огибающая без щелчков.

## Видео (`video.py`)

- 30 кадров на книжной странице (`#FAF8F4`, DejaVu Serif, формула Computer Modern);
- анимация по домену: сходящийся ряд Фурье / бегущий волновой пакет /
  сортировка столбиков;
- склейка со звуком через системный `ffmpeg`:
  `H.264 (yuv420p) + AAC + +faststart` → совместимо с Telegram `sendVideo`;
- если `libx264` недоступен — fallback на анимированный `.gif`;
- кэш `data/video/<id>.mp4` — повтор не пересобирает ролик.

## Когда выходит видео

| Режим | Как включается |
|:--|:--|
| Вечерний слот | `video.every_nth_post: 3` — каждый 3-й пост автоматически |
| Вручную | `publish --video`, `/force video`, `/preview video` |
| Только карточка | `publish --no-video`, `/preview photo` |

Карточка `.png` создаётся **всегда** — она нужна сайту и PDF-книге, даже когда
в канал уходит видео.

## Конфигурация

```yaml
video:
  enabled: true
  every_nth_post: 3
  seconds: 3.6
  frames: 30
  with_sound: true
```

## Живая осциллограмма и фонетика формул

**Осциллограмма** (`build_audiogram_mp4`): ролик собирается одним вызовом `ffmpeg`
с фильтром `showwaves` — звуковая волна голоса пульсирует прямо над колонтитулом
книжной страницы, поэтому в ленте сразу видно, что это видео со звуком:

```
[1:a]showwaves=s=936x56:mode=cline:colors=0x1E3A8A@0.85[w];
[0:v][w]overlay=72:940:shortest=1,format=yuv420p[v]
```

Цвет волны — чернила дисциплины: `math #1E3A8A`, `physics #9F1239`, `cs #B45309`.
Если фильтр недоступен — мягкий fallback на статичную картинку (`wave=False`).

**Фонетика** (`math_to_spoken_russian`): печатный текст не меняется, но копия для
диктора произносится как у лектора:

| В тексте | Диктор говорит |
|:--|:--|
| `O(N log N)` | «о большое от эн логарифм эн» |
| `O(N²)` / `O(n^2)` | «о большое от эн квадрат» |
| `O(1)` | «о от единицы» |
| `Δφ`, `Δx`, `Δt` | «дельта фи», «дельта икс», «дельта тэ» |
| `Ψ`, `φ`, `λ`, `ℏ`, `π` | «пси», «фи», «лямбда», «аш с чертой», «пи» |
| `c²` | «це в квадрате» |
| `≥`, `≤`, `≈`, `≠` | «больше либо равно», «меньше либо равно», «приближённо равно», «не равно» |
| `·`, `×`, `∫`, `∑`, `√` | «умножить на», «интеграл», «сумма», «корень из» |

## Куда уходит звук и видео

| Площадка | Режим | Доставка |
|:--|:--|:--|
| Telegram | `auto` | `sendVoice` (.ogg) ≤60 с, иначе `sendAudio` (.mp3) |
| Discord | `file` | mp3 вторым вложением webhook |
| Mastodon | `file` | mp3 как media (играет нативно) |
| Bluesky | `mp4` | **напрямую байтами**: `uploadBlob` (video/mp4) → `app.bsky.embed.video` |
| VK | `mp4` | **напрямую байтами**: `video.save` → upload_url → `video{group}_{id}` |
| Threads | `link`/`mp4` | ссылка или публичный MP4 (Threads принимает видео только по URL) |

Прямая загрузка в Bluesky и VK **не требует сайта** — ролик уходит с диска.
Для Threads нужен `SP_SITE_BASE_URL`, который теперь определяется автоматически
из `git remote get-url origin` (GitHub Pages), кроме чужого репозитория `kern`.

## Команды

```bash
python -m science_pulse.cli publish --video        # принудительно видео
python -m science_pulse.cli verify                 # медиа-smoke: звук + видео + карточка
```

Пульт: `/preview video` — прислать ролик в личку, `/force video` — опубликовать.

## Проверка

```bash
python -m unittest tests.test_sound_video -v
ffprobe -v error -show_entries stream=codec_name -of default=nw=1 data/video/<id>.mp4
```
