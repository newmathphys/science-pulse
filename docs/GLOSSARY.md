# Глоссарий SCM

| Термин | Значение |
|:--|:--|
| **SCM** | Scientific Content Machine — машина научного контента |
| **Контур 1** | добыча источников и очередь |
| **Контур 2** | текст, формулы, карточка, фильм, звук |
| **Контур 3** | публикация, идемпотентность, метрики |
| **Эшелон 1** | онлайн-источники |
| **Эшелон 2** | очередь SQLite |
| **Эшелон 3** | офлайн-бункер SymPy + CODATA |
| **PROVEN** | доказано оракулом или подписано владельцем |
| **EMPIRIC** | измерено/подтверждено экспериментом |
| **HYPOTHESIS** | гипотеза, не доказательство |
| **REFUTED** | опровергнуто |
| **UNPROVEN** | текст/заметка агента без подписи |
| **Quality gate** | 7 рубежей `StandardsChecker` |
| **CanonGate** | приёмочная комиссия поста |
| **Preflight** | предполётная проверка без публикации |
| **Vc = Tc·Fc·Hc** | объём сигнала: время × полоса × динамический диапазон |
| **Vk** | ёмкость канала внимания |
| **Шеннон** | энтропия/избыточность текста |
| **УОС/РОС** | управляющая/решающая обратная связь |
| **Нейман—Пирсон** | критерий отсева шума по ложной тревоге |
| **Калман** | фильтр очистки метрик |
| **Δ t защ** | защитный интервал между постами |
| **Moku3D** | тёмный 5-актовый 3D-фильм |
| **Book Film** | светлый книжный фильм с подсветкой слов |
| **FSRS** | модель памяти/повторения |
| **PTE** | Project Truth Extractor |
| **KERN** | ворота верификации кода, `e=1` |
| **RII** | Рациональный ИИ, детерминированное ядро |
| **NYUUI** | корпус знаний и индекс |
| **Эмбрион-Симбиот** | операторский экзокортекс |
