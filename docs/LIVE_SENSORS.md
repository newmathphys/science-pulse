# Живые датчики Планеты и Космоса (без ключей)

Сухие законы из учебника выглядят иначе, когда в формулу подставлено
**реальное сегодняшнее число**. Модуль `science_pulse/live_sensors.py` берёт
данные из четырёх полностью открытых JSON-API — **без ключей, регистраций и
платных парсеров**.

| Датчик | Источник | Что считаем |
|:--|:--|:--|
| `earthquake` | USGS Earthquakes GeoJSON | магнитуда `M` → энергия Гутенберга–Рихтера `lg E = 4.8 + 1.5·M` |
| `space_weather` | NOAA SWPC `planetary_k_index_1m` | `Kp` → класс бури G1…G5 (Максвелл, сила Лоренца `F = q(v × B)`) |
| `gravitational_waves` | LIGO/Virgo GWOSC `allevents` | массы `M₁, M₂, M_f` → `E = Δm·c²`, радиус Шварцшильда `r_s = 2GM/c²` |
| `iss_orbit` | WhereTheISS.at (МКС) | высота `h`, скорость `v` → `g(h) = G·M⊕/(R⊕+h)²` |

## Надёжность

- **Таймаут 2.5 с** (`TIMEOUT`) на каждый запрос — датчик не тормозит выпуск.
- **Детерминированный офлайн-фоллбэк**: если сети нет, подставляется типовое
  значение (M = 5.0; Kp = 3.0; GW150914; МКС 420 км), и в подписи честно
  появляется пометка `(офлайн)`.
- **Кэш 10 минут** (`CACHE_TTL`): за сборку сайта датчик опрашивается один раз.
- **Выключен по умолчанию в коде** (`ENABLED = False`): включает пайплайн по
  конфигу, поэтому юнит-тесты не ходят в сеть.
- Сбой датчика **никогда** не ломает публикацию (исключения перехватываются).

## Как число попадает в пост

`live_sensors.sensor_for_post(post)` выбирает датчик по теме (заголовок, крючок,
тело, формула), а `live_line(post)` возвращает строку для блока подписи:

```
Живой датчик:   МКС: h = 436.5 км, v = 7.65 км/с → g(h) = 8.601 м/с²
```

В подписи это отдельное выровненное поле `Живой датчик:` рядом с
`Инвариант / Верификация / Первоисточник / Применение`.

## Команды

```bash
python -m science_pulse.cli sensors          # все четыре датчика
python -m science_pulse.cli sensors --json   # машинный формат
```

В коде:

```python
from science_pulse.live_sensors import all_sensors, enable, sensor, live_line

enable(True)                      # включает датчики
all_sensors()                     # {'earthquake': {...}, 'iss_orbit': {...}, ...}
sensor("earthquake", http=fake)   # инъекция HTTP для тестов
```

## Ограничения

- Датчики дают **одно** число на выпуск — это иллюстрация, а не измерение.
- Публичные API могут менять формат; при расхождении срабатывает фоллбэк.
- Тема выбирается по ключевым словам: если тема не совпала, поле просто не
  появляется (никакого «случайного» числа в посте).
