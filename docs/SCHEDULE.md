# 4-уровневый календарь проекта

Ритм как у крупного научного издательства: точные суточные слоты, событийные
«молнии», недельные ритуалы и месячная самопрофилактика.

## Уровень 1 — сутки: 4 слота (`schedule_slots`, МСК)

| Время | Слот | Что выходит |
|:--:|:--|:--|
| **09:00** | `math` | аксиомы, теоремы, ряды (OEIS), геометрия, анализ |
| **13:00** | `cs` | алгоритмы, структуры данных, код, Big-O, графы |
| **17:00** | `physics` | законы природы, поля, кванты, эталоны СИ (CODATA) |
| **21:00** | `satellite_lab` | прикладная лаборатория: InSAR/NDVI/океан/GRACE/вихри, живые датчики, фильм Moku3D |

Слот определяется по местному времени (`rituals.daily_domain`) и передаётся
пайплайну как дисциплина выпуска. Прикладной слот идёт по физике
(`SATELLITE_DOMAIN`), потому что все лаборатории — физические.

## Уровень 2 — событие: «Молния науки»

`trending.auto_publish_min_likes: 350` — если радар мировых новостей находит
прорыв выше порога, он выходит внеочередным спецвыпуском (или уходит оператору
с кнопкой `/pick 1 now`). Порог `0` отключает механизм.

## Уровень 3 — неделя (вечерний слот 21:00 МСК)

| День | Ритуал | Что делает |
|:--|:--|:--|
| **Пятница** | `friday_quiz` | нативная викторина `sendPoll` по одному из законов недели (освежение памяти) |
| **Суббота** | `saturday_cheatsheet` | сводная карточка-шпаргалка недели + пересборка `radio_mix.mp4` |
| **Воскресенье** | `sunday_book` | PDF-книга проекта + бэкап `science.db` + сводка `/ab` оператору |

## Уровень 4 — месяц (1-е число)

`monthly_maintenance`:
1. продление 60-дневного токена Threads (`refresh_access_token`);
2. `VACUUM` базы + очистка медиа (`cleanup_old_media`, `media.keep_last`);
3. паспорт Атласа оператору: опубликовано, в очереди, параграфов, учёных,
   констант, распределение по дисциплинам.

## Идемпотентность

Факт выполнения хранится в `kv`: `last_friday_quiz` / `last_saturday_cheatsheet`
/ `last_sunday_book` (ключ недели `YYYY-Www`) и `last_monthly_maint`
(`YYYY-MM`). Повторный запуск в тот же день/месяц **ничего не дублирует** —
это проверено тестами.

## Команды

```bash
python -m science_pulse.cli rituals --dry-run   # что должно сработать сейчас
python -m science_pulse.cli rituals             # выполнить должное
python -m science_pulse.cli daemon              # фон: слоты + ритуалы по расписанию
```

Фоновый демон (`run_daemon`) для каждого слота вычисляет дисциплину, публикует
выпуск, а затем вызывает `run_rituals` — так недельные и месячные задачи
срабатывают сами, без отдельных cron-записей.

## Проверка

```bash
python -m unittest tests.test_multi_horizon_schedule -v   # 15 тестов
```

## Ограничения

- Слот определяется часом: если запустить демон позже слота, выйдет дисциплина
  ближайшего прошедшего слота (поведение осознанное).
- Воскресный PDF требует `typst`; без него ритуал сообщает причину и не падает.
- Продление токена Threads работает только при заданном `TH_ACCESS_TOKEN`.
