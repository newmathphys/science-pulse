# Moku3D — короткометражный фильм из одного уравнения

Референс: серия `Moku3D` на `mokujiro.com` — «One equation per study, made
visible as a short film». Модуль `science_pulse/moku_film.py` превращает
параграф канона в **30-секундный фильм из 5 актов**: в кадре всегда ровно одна
строка смысла, в центре — вычисляемая геометрия, сверху — технический штамп.

## Раскадровка (5 актов)

| Акт | Что происходит | Источник строки |
|:--|:--|:--|
| I · Постановка | исходная конфигурация системы | `post.hook` |
| II · Закон в действии | уравнение включается, точки приходят в движение | `formula_plain` |
| III · Смена ракурса | камера плавно облетает геометрию (азимут + наклон) | `meta["concept"]` |
| IV · Точный расчёт | параметр меняется в кадре, форма перестраивается | `post_proof.computed_example` |
| V · Инвариант и задача | финальная форма + вопрос для размышления | `challenge.question` |

Правило стиля: **одна строка на акт**. Кегль подбирается автоматически
(`_fit_text`) так, чтобы строка физически влезла в кадр; при нехватке места она
обрезается по словам с многоточием. Строка появляется и гаснет по `alpha fade`
(`_fade`, 14 % длительности акта на краях).

## Геометрия по дисциплинам (`Scene3D`)

| Дисциплина | Что считается |
|:--|:--|
| `physics` | **задача трёх тел**: классическая «восьмёрка» Ченсинера–Монтгомери (три равные массы на одной замкнутой орбите). Интегрирование — leapfrog, чтобы орбита не расплывалась; система центрируется по центру масс и наклоняется на 0.62 рад, чтобы 3D-камера видела объём, а не линию |
| `math` | 3D-кривая Фурье `Σ (cos kt, sin kt, sin kt/2)/k`; **в Акте IV число гармоник меняется `n = 1 → 3`**, и форма мгновенно перестраивается |
| `cs` | решётка 3×3×3 и трассируемый путь алгоритма; в Акте IV меняется порядок обхода (`порядок A → B`) |

Проекция — перспективная: `_project` считает `depth = z` и масштаб
`focal / (focal − z)`, поэтому ближние точки и линии **толще и ярче**
(сортировка по глубине, Z-буфер).

## Камера и HUD

- `_camera`: в Акте III азимут облетает полный круг (`θ + 2π·progress`), в
  остальных актах — медленный дрейф; наклон `φ` слегка «дышит».
- HUD (`_draw_hud`): слева `STUDY § X.Y · ТОЧНАЯ ЧИСЛЕННАЯ МОДЕЛЬ`, под ней
  уравнение поста и живой счётчик (`t = 2.40 с · |v| = 1.576` для физики,
  `n = 3 · t = 5.02` для математики, `шаг = 13/27 · порядок A` для
  информатики); справа — метка `АКТ III · Смена ракурса`. Ширина левой колонки
  вычисляется от ширины правой, поэтому **наложений нет**.

## Сборка и звук

1. Кадры рендерятся в PNG (`render_frames`), `size` × `size`, `fps`.
2. Звук: `sound.sonify` (гармонический пад) на всю длину фильма; если задан
   `audio_path` — берётся он (например, озвучка `voice.py`).
3. `ffmpeg`: `-c:v libx264 -pix_fmt yuv420p -preset ultrafast -movflags +faststart`
   (+ `-c:a aac -b:a 128k -shortest` при звуке). Без `ffmpeg` фильм не
   собирается — возвращается `None`, публикация деградирует на карточку.
4. Рабочие кадры удаляются (`shutil.rmtree`), готовый файл кэшируется в
   `data/films/<id>.mp4` (`film_for_post`).

## Настройки

```yaml
moku3d:
  size: 720             # сторона кадра
  fps: 24
  seconds_per_act: 5.0  # × 5 актов = 30 секунд
  audio: true
```

## Команды

```bash
python -m science_pulse.cli film                 # следующий пост в очереди
python -m science_pulse.cli film --domain physics
python -m science_pulse.cli film --post-id <id> --send   # отправить в админ-чат
```

В Пульта: `/film [ID]` — собрать и прислать фильм в личный чат (без публикации
в канал). Если у поста дизайн `moku3d`, публикатор Telegram отправляет фильм
через `sendVideo` вместо статичной карточки; на сайте страница параграфа
получает блок `<video>` (файл копируется в `dist/films/`).

## Проверка

`tests/test_moku_film.py`: 5 актов и ровно одна строка на акт, ограниченность
«восьмёрки», переключение гармоник `n = 1 → 3`, перспектива проекции, число
кадров и размер PNG, валидный `.mp4` (skip без `ffmpeg`), очистка рабочих
кадров.

## Ограничения

- Без `ffmpeg` фильма нет (карточка остаётся).
- Голос (`edge-tts`) необязателен: базовый звук — синтез `sound.py`.
- Фильм не коммитится в Git (`data/films/` вне репозитория); для Threads нужен
  публичный URL — включается после деплоя сайта на HTTPS.
