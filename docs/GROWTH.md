# Рост аудитории SCM: Threads → Telegram → сайт

Цель: собрать аудиторию по математике, физике и информатике из Threads и
тематических каналов, используя **уникальность SCM**: детерминированный
источник + формула + проверяемое следствие. Без LLM-текста и без кликбейта.

## 1. Позиционирование

```text
SCM — не «ещё одна научная лента».
SCM — проверяемая наука: источник, формула, карточка, следствие.
```

Что видит читатель:

- конкретный факт/теорему/алгоритм;
- формулу в Unicode;
- источник;
- ссылку на полный разбор и Telegram;
- серию, а не случайный шум.

## 2. Уникальные форматы Threads

| Формат | Для чего | Структура |
|:--|:--|:--|
| **ТЕОРЕМА ДНЯ** | математика | крючок → формула → следствие → хештеги |
| **ЯВЛЕНИЕ ДНЯ** | физика | вопрос → модель → формула → применение |
| **АЛГОРИТМ ДНЯ** | CS | задача → код/сложность → где применяется |
| **ПАРАДОКС** | все | вопрос-парадокс → короткое разрешение |
| **ЗАДАЧА** | все | условие → ответ в реплае |
| **МОСТ** | все | пост → сайт/Telegram/книга |

Первый пост Threads **без внешней ссылки** (алгоритм ленты не любит ссылки).
Ссылки и CTA — во втором посте-реплае.

## 3. Воронка

```text
Threads: крючок + формула
        ↓ (реплай)
Сайт: полный разбор, график, тренажёр
        ↓
Telegram @newmathphys: серия, файлы, книга
        ↓
Продукт: книга / курс / консультация
```

UTM:

```text
?utm_source=threads&utm_medium=social&utm_campaign=scm&utm_content=<post_id>
```

`growth` CLI уже строит такие ссылки.

## 4. Ритм на 30 дней

| Неделя | Действие |
|:--|:--|
| 1 | 2 поста/день в Threads, 3 осмысленных ответа/день в тематических ветках |
| 2 | 10 каналов в реестр, 5 персональных предложений кросс-поста |
| 3 | 3 кросс-поста с каналами, 1 «задача недели» |
| 4 | замер: подписчики, охваты, ответы, переходы по UTM |

Не спамить. Один канал — одно персональное предложение с конкретным постом.

## 5. Реестр каналов

```bash
./sp growth target-add --platform telegram --name "Канал X" \
  --url https://t.me/... --topic physics --audience 12000 --notes "кросс-пост"
./sp growth targets
./sp growth report
```

Статусы: `new → contacted → agreed → posted → measured`.

## 6. Команды

```bash
./sp growth plan                 # формат, крючки и Threads-цепочка
./sp growth plan --post-id ID
./sp growth utm https://example.org/post/ID --post-id ID
./sp growth collect              # подписчики Telegram/Threads + снимок
./sp growth dashboard            # data/growth_report.md и .html
./sp growth targets
./sp growth report
```

## Что собираем

| Метрика | Источник |
|:--|:--|
| подписчики Telegram | `getChatMemberCount` |
| подписчики Threads | Graph API `followers_count` (если отдаёт) |
| просмотры/реакции/ответы постов | `metrics --collect` |
| дизайны/оформление | `themes.design_stats` |
| посты/очередь/ошибки | SQLite `posts` |
| каналы-партнёры | `growth.db` |

Отчёт: `data/growth_report.md` + `data/growth_report.html`.
Если API не отдаёт показатель — честно `skipped`, а не выдуманное число.

## 7. KPI

- подписчики Telegram/Threads;
- просмотры и ответы Threads;
- переходы по UTM;
- глубина сайта (страниц/сессия);
- конверсия в книгу/курс/консультацию.

Метрики хранятся в `metrics` и `growth.db` (события реестра).

## 8. Правила

1. Не публиковать без источника.
2. Не выдавать гипотезу за `PROVEN`.
3. Не покупать подписчиков и не спамить.
4. Один смысл — один формат; не размазывать.
5. Лучший пост недели — в закреп и в кросс-пост.
